# Cidade Pixel

Jogo de vida na cidade em pixel art.

## Baixar

**[Baixar o instalador (versão mais nova)](https://github.com/Adryan953/lifepixel/releases/latest/download/CidadePixel-Setup.exe)**

## Atualizar

Feche o jogo, baixe o instalador novo pelo link acima e instale por cima. Seu personagem e seu mundo continuam (ficam em `%LOCALAPPDATA%\CidadePixel`).

Todas as versões: [Releases](https://github.com/Adryan953/lifepixel/releases)
